# QuietMap 小程序 UI 规范（V1）

> 适用于 `miniapp/` 目录下页面，覆盖地图视图、列表卡片与标签组件。

## 1. 基础视觉规范
- **色板**
  - 品牌主色：`#4C6FFF`（渐变可搭配 `#6F8DFF`）
  - 背景浅色：`#F7F8FA`，卡片白底：`#FFFFFF`
  - 辅助灰：标题 `#1F2A44`、正文 `#4B556A`、次要信息 `#7F8A9F`
  - 噪音等级：安静 `#34C759`、一般 `#F7B500`、嘈杂 `#FF3B30`
- **圆角与间距**
  - 主要容器圆角 24rpx，次级 16rpx，胶囊 12rpx；
  - 版心左右留白 32rpx，元素间距 16~24rpx。
- **阴影与质感**
  - 卡片阴影：`0 10rpx 30rpx rgba(46, 60, 93, 0.08)`，浮层可适当加强；
  - 页面背景使用浅色渐变，保证地图与卡片的层次。

## 2. 组件与交互
- **地图 Map**
  - marker 颜色与 callout 背景与噪音等级同步；
  - 在地图左下角放置深色半透明提示条，说明交互（拖动刷新 / 点击标记）；
  - 小区页可叠加 polygon 轮廓，保证 stroke 颜色与品牌色一致。
- **列表卡片**
  - 使用白底 + 阴影 + 大圆角，点击态上浮 4rpx + 高亮描边；
  - 标题 32~34rpx 加粗，次要信息 24~26rpx；
  - 标签行可复用胶囊样式，保持统一的留白和圆角。
- **标签 NoiseLevelTag**
  - 胶囊形，包含颜色小圆点；
  - 背景使用对应颜色的 15% 透明度，文字同色。
- **悬浮卡片**
  - 底部固定 + 毛玻璃（白色 90% 透明），突出主按钮渐变；
  - 包含名称、分数/推荐信息、跳转按钮。

## 3. 布局与响应
- 首页：上方品牌介绍 + 城市选择胶囊；地图区域置于视觉焦点；列表滚动区域保持足够留白；
- 小区页：卡片呈现小区摘要，地图 + 提示条，列表展示筛选结果；
- 所有文本/提示默认中文，保持简洁可读。

## 4. 适配与后续
- 仅针对微信小程序 weapp 平台；
- 若新增功能（筛选面板、地图控件）应复用色板与圆角规范，避免跳脱风格；
- 图标可逐步替换为品牌化资源，当前占位使用系统 marker 与胶囊说明。
